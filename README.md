Welcome to the **IntentJS Landing Page** repository! This project contains the frontend code for the official website of IntentJS, a web application framework built on top of NestJS.

## 🚀 Overview
IntentJS is designed to provide declarative APIs for developing and shipping sophisticated web applications. While NestJS offers excellent structure, IntentJS enhances it by integrating necessary features like authentication, database integration, task scheduling, and more.

This landing page showcases IntentJS, its features, and how it simplifies backend development.

## ✨ Features
- Responsive design for all devices
- Modern UI built with Next.js and Tailwind CSS
- SEO-optimized for better discoverability
- Showcases IntentJS features and benefits
- Documentation links and community section

## 🏗 Tech Stack
- **Frontend** - Next.js, React, Tailwind CSS
- **Icons** - Lucide Icons
- **Component Library** - Shadcn UI

## 📦 Installation
To set up the project locally, follow these steps:

```sh
git clone https://github.com/your-username/intentjs-landing.git
cd intentjs-landing
npm install  # or yarn install
```

## 🚀 Running the Project
Start the development server with:

```sh
npm run dev  # or yarn dev
```

This will launch the app on `http://localhost:3000/`.

## 📤 Deployment
The project is optimized for deployment on **Vercel**. To deploy, run:

```sh
vercel
```
